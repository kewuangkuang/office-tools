# 回单卡包助手（原型）

这是办公工具箱 PDF 回单拆分结果的浏览器插件消费端，不会上传回单内容。

## 使用

1. 在办公工具箱的 PDF 回单模式或模板框选模式中完成拆分。
2. 第一次使用时，打开 Chrome 的扩展管理页，开启开发者模式，选择“加载已解压的扩展”，选中本目录。
3. 点击“导出回单卡包”。插件已安装且工具页已刷新时，卡包会自动同步并设为当前卡包，不再下载 ZIP。
4. 如果插件没有连接，工具会自动下载 ZIP；此时再点击插件图标手动导入。手动导入只需要在插件未连接或换电脑时使用。
5. 打开报销网页，展开页面上的“回单卡包”，点击“点击网页金额查找”，再点击金额数字。
6. 在候选卡片中预览并点击“选择”。插件会尝试把 JPG/PDF 填入当前页面的文件上传框；网页仍需由用户确认提交。

## 当前边界

- 卡包和回单文件只保存在浏览器本地 IndexedDB。
- 自动同步只在办公工具箱页面导出卡包时触发；网页不能静默安装 Chrome 插件，插件首次仍需手动加载一次。
- 搜索按规范化后的金额精确匹配；金额重复时会展示多个候选，不自动替用户决定。
- 通用页面可以读取点击位置附近的金额；特殊上传组件可能需要后续做站点适配。
- 这是原型扩展，`<all_urls>` 权限只为验证通用点击场景；正式使用前应收窄到实际报销网站域名。
